# 이채현 디지털 명함 사이트

파일 구성
- index.html : 모바일 명함 페이지
- contact.vcf : 연락처 저장용 vCard
- card.png : 명함 이미지

## GitHub Pages에 올리는 방법
1. GitHub에 로그인
2. New repository 생성 (예: my-card)
3. Public 선택
4. 이 폴더의 3개 파일을 저장소 최상위에 업로드
5. 저장소 Settings > Pages
6. Build and deployment의 Source를 "Deploy from a branch"로 선택
7. Branch를 main / (root) 로 선택 후 Save
8. 잠시 뒤 표시되는 https://사용자이름.github.io/my-card/ 주소로 접속
9. 그 URL로 QR 코드를 생성

주의:
- 전화번호/이메일/명함 이미지는 공개 웹에 노출됩니다.
- 브라우저/OS에 따라 다운로드 전에 확인 과정이 표시될 수 있습니다.
